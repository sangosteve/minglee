# WhatsApp CRM

A modern, full-stack WhatsApp CRM system with contacts management, conversations, analytics, and automations.

## 🚀 Features

### Core Features
- **📱 WhatsApp Integration** - Connect multiple WhatsApp Business accounts
- **👥 Contacts Management** - Add, edit, search, and tag contacts
- **💬 Conversations** - Real-time messaging with contacts
- **📊 Analytics Dashboard** - Performance metrics and insights
- **🤖 Automations** - Automated workflows and campaigns
- **📤 Broadcasts** - Send bulk messages to segments
- **🏷️ Tags & Labels** - Organize contacts with custom tags
- **👥 Team Collaboration** - Multi-user support with roles

### Technical Features
- **🔐 Authentication** - JWT-based auth with Google OAuth
- **📱 Responsive UI** - Mobile-friendly dashboard
- **⚡ Real-time Updates** - WebSocket for live messaging
- **🔧 TypeScript** - Full-stack TypeScript for type safety
- **🗄️ PostgreSQL** - Relational database with Drizzle ORM
- **🔒 Security** - Rate limiting, input validation, CSRF protection
